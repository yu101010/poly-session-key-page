先看这一条：本页不保存任何东西，刷新或关掉页面，所有内容立即清空，生成的密钥无法找回。最后一步拿到 5 个值后，请先全部复制保存好，再关闭页面。

安全说明

密钥不出手机

  • Session 私钥在你的手机上、本页内生成，只用于在本页本地签名，从不发送到任何服务器——发出去的只有签名结果。
  • 你的钱包主私钥从头到尾不离开 OKX 钱包，本页只能请钱包弹窗签名，读不到它。
  • Relayer API Key 只会发送给 Polymarket 官方的 relayer-v2.polymarket.com；L2 凭据只向官方 clob.polymarket.com 申请。本页不连接任何其他服务器（仅从 CDN 加载 ethers.js 库）。
  • 本页不使用任何本地存储：不写 Cookie、不写 localStorage，刷新即清空。
  • Session Key 权限仅限 CLOB 交易，不能提款、不能转账；万一泄露，损失上限是被乱下单，请第一时间在 Polymarket 里撤销它。
遇到报错先看红色提示里的说明；最常见的是网络不是 Polygon、地址填错、或手机时间不准（时间偏差过大时签名会过期，请把手机时间设为自动同步）。
